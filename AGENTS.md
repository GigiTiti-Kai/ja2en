## Claude Code guidance bridge

このブロックは `$sync-claude-guidance` が管理する。正本は下記の Mandatory startup reads / Conditional reads に列挙する Claude guidance files であり、ルール本文をここへ複製しない。ユーザーグローバルの Claude ルールは `~/.codex/AGENTS.md` が担当する。

### Mandatory startup reads

作業内容に関わらず、開始時に以下をすべて読むこと:

1. `CLAUDE.md`

これは Claude Code の条件付き読み込みを Codex の明示的な事前条件で近似する運用。ルールファイルや `paths:` を変更したら `$sync-claude-guidance` を再実行すること。
